About this project

AI Travel Planner ek agentic AI project hai, jo LangChain aur Groq ke LLM (openai/gpt-oss-20b) se bana hai.

Agent flights, hotels, places, weather aur budget ke tools call karke trip plan banata hai. Hotels, Places aur Itinerary tabs local data se chalte hain, isliye ye Groq ki limit use nahi karte.

Data: flights.json, hotels.json, places.json (sample data).

Weather: Open-Meteo API (free, no key).

Backend: FastAPI. Frontend: HTML, CSS, JavaScript.
